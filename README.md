# Personal Portfolio & Dashboard

A minimal portfolio with an interactive developer CLI terminal, case studies, and a dynamic dashboard powered by **Next.js 16**, **shadcn/ui**, **Tailwind CSS**, **Express 5**, and **Prisma 7 with PostgreSQL**.

---

## 🛠 Technology Stack

- **Frontend (`/client`)**:
  - Next.js 16 (App Router, Turbopack, Cache Components)
  - shadcn/ui (Nova / Radix base components)
  - Tailwind CSS v4 & Next Themes (Dark / Light mode)
  - Google Fonts (Inter & JetBrains Mono)
  - Package Manager: **Bun**
- **Backend & Database (`/server`)**:
  - Express 5.3 (RESTful API, Helmet, CORS, Central Error Handling)
  - Prisma 7.10 with `@prisma/adapter-pg` driver adapter
  - PostgreSQL (Neon / Supabase / Prisma Postgres / Local)
  - JWT Authentication for Dashboard & Constant-time credential checks
  - Zod validation schemas
  - Package Manager: **npm**

---

## 🚀 Quick Start

### 1. Backend Setup (`/server`)
1. In `server/.env` (or copy from `server/.env.example`), provide your PostgreSQL database URL:
   ```env
   DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/portfolio?sslmode=require"
   PORT=5000
   JWT_SECRET="<auto-generated-secret>"
   ADMIN_EMAIL="asifshahriartauhid@gmail.com"
   ADMIN_PASSWORD="change-me-please"
   CORS_ORIGIN=http://localhost:3000
   ```
2. Push database schema & seed initial portfolio data:
   ```bash
   cd server
   npm run db:push
   npm run db:seed
   ```
3. Start the API server:
   ```bash
   npm run dev
   ```
   API runs at `http://localhost:5000`.

### 2. Frontend Setup (`/client`)
1. Start the Next.js development server:
   ```bash
   cd client
   bun run dev
   ```
2. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔐 Administrative Dashboard (`/dashboard`)

- **URL**: `http://localhost:3000/dashboard`
- **Credentials**: Configured securely via `ADMIN_EMAIL` and `ADMIN_PASSWORD` in `server/.env`

### Manageable Sections:
1. **Profile & Hero**: Designation, Name, Alias, Photo URL, Resume Download URL, Hero narrative, About Me paragraphs, Highlights chips, Email, Phone, WhatsApp, and Availability status toggle.
2. **Projects**: Add, edit, and delete projects with images, categories, full descriptions, technology stacks, live URLs, GitHub repositories, technical challenges, and future roadmaps.
3. **Skills & Categories**: Categorize skills (Frontend, Backend, Database, Languages, Tools) and configure proficiency meters (0–100%).
4. **Experience**: Add, edit, and delete professional roles, companies, dates, highlights, and tech stacks.
5. **Education**: Update degrees, universities, coursework, results, and years.
6. **Social Links**: Manage hero and footer links to GitHub, LinkedIn, X, and Facebook.
7. **Contact Inbox**: Read messages dispatched from the public contact form, mark as read, or delete.
